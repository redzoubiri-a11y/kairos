# Dharra — Livrable N : « ذرّة اليوم » — réserve de 14 jours

> Messages courts pour le canal WhatsApp (livrable C.3, étage MOFU/rétention).
> **1 message = 1 fitre.** Format volontairement bref (chat, pas article) : un
> déclencheur, une source vérifiée, une action minuscule.
> **À coller en arabe uniquement** dans le canal — la ligne FR sous chaque
> message est juste un repère interne pour toi, ne pas la publier.
> Sources : voir `K_sources_verifiees.md` pour les références exactes.

لا وعظ طويل، لا إزعاج. ذرّة تكفي لتبدأ يومك بوعي أكبر.

بانتظاركم كل يوم.

```

## Jour 2 — La constance (H1 · Bukhârî 6464 / Muslim 783)

```
أَحَبُّ الأَعْمَالِ إِلَى اللَّهِ أَدْوَمُهَا وَإِنْ قَلَّ.

لست بحاجة إلى عمل كبير اليوم.
اختر عملاً صغيراً واحداً، وكرّره — الاستمرار أثقل من الحماس.

— ذرّة
```
*(FR — repère : « Les actes les plus aimés d'Allah sont les plus constants, même peu. »)*

## Jour 8 — Le tawakkul (H13 · Tirmidhî 2344, hasan sahîh)

```

## Après le jour 14
Reboucler avec des thèmes nouveaux issus des scripts (Arc 3 : ridâ, protocole colère, 30 jours) ou
répéter le cycle en variant la formulation — la répétition espacée est justement le principe
pédagogique du calendrier F. Éviter de publier deux jours sans message : la régularité est
l'actif de rétention (C.3, étage 4).

## Rappel pratique
- Publie **un seul message par jour**, à heure fixe si possible (ex. après Fajr ou en soirée).
- Pas de lien, pas de CTA dans ces messages — le canal sert la **relation**, pas la conversion
  directe (l'app se glisse plus tard, par exemple un jour sur 7, jamais plus).
- Signature constante **« — ذرّة »** pour la reconnaissance de marque.
